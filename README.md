# Healthcare SQL Reporting Project

## Project Overview
This project analyzes sample healthcare appointment and claims data using MySQL. The goal was to practice SQL reporting skills by creating relational tables, inserting sample data, joining tables, and analyzing appointment outcomes, provider activity, claim statuses, and revenue gaps.

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## Database Tables
- patients
- providers
- appointments
- claims

## Key SQL Skills Used
- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate functions
- Calculated fields

## Business Questions Answered
1. How many claims are in each claim status?
2. Which providers had the highest billed amounts?
3. What is the revenue gap between billed and paid amounts?
4. How many appointments were completed, cancelled, or no-show?
5. Which patients had appointments with which providers?

## Sample Insight
The analysis identified revenue gaps by claim status and provider, allowing the organization to better understand unpaid, denied, pending, and partially paid claims.
